- **담당업무**
  - 병원 문진 Agent 개발 (Spring Boot 기반)
    - 환자 정보 수집 및 전달
      - Spring Boot와 스케줄러를 활용하여 병원 PC에서 주기적으로 환자 정보를 API를 통하여 수집합니다.
      - 병원 요구사항에 따라 API 호출 또는 데이터베이스 조회 방식으로 환자 정보를 가져옵니다.
    - 문진 예약 및 알림 시스템
      - 수집된 환자 정보를 문진 예약 API에 맞게 데이터를 변환(Parsing & Mapping) 후 병원 검진 예약 API로 전송합니다.
      - 환자에게 온라인 문진표 링크를 SMS/카카오톡 알림 등으로 자동 발송합니다.
    - 문진 결과 저장 및 연동
      - 스케줄러를 통해 주기적으로 문진 결과를 조회하고 데이터를 동기화 합니다.
      - 병원의 요구사항에 따라 문진결과는 URL로 생성하여 API로 전송하거나 병원 지정 테이블에 쿼리를 이용해 직접 저장합니다.
